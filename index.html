こまりごとラボ暮らしの小さな悩みを、ツールで解決する。

「税込でいくら？」「これ、どう計算するんだっけ」。暮らしや仕事のなかの「ちょっと困った」を、ブラウザですぐ使える無料ツールで一つずつ解決していきます。登録も、アプリのインストールもいりません。

  • 確定申告、レシートの束から始めるのがつらい サロンの確定申告準備シート

  • 保育園の準備、毎朝なにか忘れてしまう 準備チェックつきの育児記録アプリ「こそだてノート」

すぐ使える、
無料ツール

どれも登録不要・無料です。入力した内容はお使いの端末の中だけで計算し、どこにも送りません。

「税込でいくら？」がすぐ知りたい

かんたん電卓

式が見えるので打ち間違いに気づける。税込・税抜（10%・8%）、%引き、履歴とコピーにも対応。

使ってみる → 「端数、どうしよう…」幹事のお悩みに

割り勘計算

100円単位の切り上げ、上司は多め・飲まない人は少なめの傾斜つきで計算。LINEに貼れる案内文もコピーできる。

使ってみる → 「締め切りまで、あと何日？」をすぐに

日数計算

2つの日付の間の日数、○日後・○日前の日付、今日からあと何日かがわかる。初日を含める・含めないも選べる。

使ってみる → 「平成○年生まれって、今何歳？」書類の前に

年齢・和暦早見表

生年月日から満年齢・数え年・学年の目安。西暦⇔和暦の変換と、1926年〜今年の早見表つき。

使ってみる → 「育休中、いくらもらえる？」家計の見通しに

育休給付金の計算

月給と期間から、育児休業給付金と「手取り10割」の出生後休業支援給付金の目安を計算。2026年8月からの上限額に対応。

使ってみる → 新しい 「時給1,200円って、年収にするといくら？」

時給・月給・年収の換算

どれか1つを入れると、時給・日給・月給・年収をまとめて換算。勤務時間・日数・ボーナスも変えられる。

使ってみる → 新しい 「ポイント込みだと、どっちが安いの？」買う前に

ポイント還元込みの比較

2〜3店の価格・送料・クーポン・ポイントから実質価格を出して、いちばん安い店と差額がわかる。2つの計算方式に対応。

使ってみる → 新しい 「この文、Xの140字に収まる？」投稿の前に

文字数カウント

貼るだけで文字数と行数。X・Threads・Instagramの上限まであと何文字か、原稿用紙の枚数もわかる。

使ってみる → 新しい 「打つより、しゃべった方が早い」ときに

音声文字起こし

話すだけで日本語がその場で文字に。キーボードで直して、ボタンひとつでコピー。※音声はブラウザの音声認識（Google・Appleなど）で変換されます。

使ってみる → 新しい 「やらなきゃいけないのに、やる気が出ない…」

やる気スイッチ診断

質問に答えると、心理学・行動経済学の知見から今の状態に合う方法を3つと、いますぐできる一歩がわかる。自分用とチーム・部下用。

使ってみる → 新しい 「Owndが終わる。何をどこに移せばいいの？」

Ameba Owndの引っ越しツール

お店の情報を入れると、新しいサイトに貼れる1ページ分の文章とHTMLができる。Owndに出す移転のお知らせ文と、書き出し〜取り込みの手順チェックつき。

使ってみる → 新しい 「家賃や光熱費、何割を経費にすればいいの？」

家事按分の計算

自宅の一部で仕事をしている人向け。家賃・電気・ネットなどを面積と時間の割合で計算し、費目ごとの年額と、根拠メモをコピーできる。

使ってみる → 新しい 「掲載費、ちゃんと元が取れてる？」

掲載費の元が取れるか計算

集客サイト・予約サイトに掲載しているお店向け。新規1人あたりの費用と、元が取れる人数、今月の差し引きを、初回だけとその後の来店も入れた見込みで出す。媒体を3つまで並べられる。

使ってみる → 新しい 「メルカリで売れたら、手元にいくら残る？」

フリマ利益ノート（メルカリの利益計算）

販売手数料・送料・仕入れ値から利益をすぐ計算。目標の利益から売値を逆算、値下げしたときの利益、取引の記録と月ごとの集計まで。キャンペーン中の送料も自由に入れられる。
